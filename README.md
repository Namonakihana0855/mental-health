こころの回復サポート

心の状態をセルフチェックし、日々の状態を振り返るためのWebアプリです。

🌱 コンセプト

「今日は少し調子が悪い」

「何となく気分が落ち込んでいる」

そんなときに、自分自身の状態を簡単に振り返り、無理をせず現在の状態を確認できることを目指しています。

医療機関による診断を代替するものではなく、セルフケア・日々の振り返りを目的としたアプリです。

✨ 主な機能

* 心の状態をチェックする質問機能
* 回答結果の表示
* スマートフォンで利用しやすい画面設計
* シンプルで直感的に操作できるUI

🛠 使用技術

* HTML
* CSS
* JavaScript
* GitHub
* Netlify

💡 制作の目的

日常生活の中で、自分の状態を簡単に振り返ることができるツールを作りたいと考え、制作しました。

AIを活用しながら、アイデアの整理、機能設計、コード作成、修正、公開までの制作プロセスを経験しています。
